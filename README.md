🎓 Student Rank Management System
Aa ek Python-Flask based web application che je student records manage karva ane rank generate karva mate banavelu che. Aa project Firebase ane SQLite banné na features ne dhyan ma rakhi ne banavyu che.

🌟 Key Highlights
Automated Ranking: Student na marks na adhare automatic rank generate thay che.

Data Flexibility: Tame Excel (.xlsx) file mathi pan data load kari sako cho.

Cloud Ready: Vercel par deploy karva mate vercel.json file ready che.

Database Management: SQLite (.db) no upyog karine data secure save thay che.

🛠️ Tech Stack
Backend: Python & Flask

Frontend: HTML5, CSS3

Database: SQLite / Firebase Firestore

Deployment: Vercel

📂 Project Structure Overview
app.py: Project nu core logic ane routes.

student_records.xlsx: Bulk data entry mate ni sample file.

templates/: Badha HTML pages (Dashboard, Rank List).

requirements.txt: Project run karva mate jaruri libraries.

🚀 How to Use?
Repository ne Clone karo.

pip install -r requirements.txt command thi libraries install karo.

python app.py thi local server start karo.

Browser ma [http://127.0.0.1:5000](http://127.0.0.1:5000) open kari ne ranks check karo.
